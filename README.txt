IMPORTANT — GITHUB PAGES:
Extract the ZIP, then upload the CONTENTS of the extracted folder (all HTML files, style.css, script.js and the complete assets folder) directly into the ROOT of your GitHub repository. Do not upload only one HTML file. The assets folder must remain alongside certificates.html.

Then open Settings > Pages, choose Deploy from a branch, select main and / (root), and Save.
